# Trip Quest 🎒 — 감성 여행 준비물 체크 웹앱

> 단순한 체크리스트는 그만! 설레는 미션과 랜덤 보상 시스템이 결합된 감성 여행 다이어리 & 퀘스트 게임 웹 애플리케이션입니다.

---

## ✨ 핵심 컨셉 & 디자인
- **디자인 무드**: 따뜻한 아이보리 (`#FAF7F2`), 세이지 그린 (`#6B8E7B`), 파스텔 옐로 (`#F4C430`) 컬러 팔레트의 감성 여행 다이어리 스타일
- **인터랙티브 캐릭터**: 진행률에 따라 표정과 대사가 변화하고 액세서리를 착용할 수 있는 여행 가방 캐릭터 **'캐리(Carry)'**
- **완벽한 반응형**: 데스크톱 탭 네비게이션 & 모바일 하단 플로팅 네비게이션 제공

---

## 🚀 주요 기능

### 1. 여행 준비물 체크리스트
- **6대 필수 카테고리 내장**:
  - 👕 **의류**: 속옷, 양말, 티셔츠, 바지, 잠옷, 겉옷
  - 🫧 **세면도구**: 칫솔, 치약, 샴푸, 클렌징폼, 스킨케어 제품
  - 🔌 **전자기기**: 휴대폰, 충전기, 보조배터리, 이어폰, 카메라
  - 📑 **여행 서류**: 신분증, 여권, 항공권, 숙소 예약 내역
  - 💊 **의약품**: 상비약, 밴드, 소화제, 진통제
  - 🎒 **기타**: 지갑, 현금, 우산, 물병, 에코백
- **핵심 사용성 기능**:
  - 준비물 체크박스 및 완료 항목 부드러운 취소선 처리
  - 새 준비물 추가 (카테고리 선택 및 필수 여부 지정) & 항목 삭제
  - 실시간 검색 기능 (준비물 이름 필터링)
  - 카테고리별/완료상태별 (전체 / 준비 완료 / 미완료) 필터링
  - 실시간 진행률 및 카테고리별 남은 개수 연동

### 2. 경험치(XP) 및 레벨 시스템
- **공정한 경험치 규칙**:
  - 준비물 최초 체크 시 **+5 XP**
  - 체크 해제 후 재체크 시 **중복 경험치 지급 방지** (`rewardedItemIds`)
  - 카테고리 내 모든 준비물 올클리어 시 보너스 **+20 XP** (`rewardedCategoryIds`)
- **성장과 레벨업**:
  - 레벨 단계: 설레는 여행 꿈나무(Lv.1) ➔ 호기심 가득 배낭족(Lv.2) ➔ 길 위의 모험가(Lv.3) ➔ 노련한 자유여행가(Lv.4) ➔ 글로벌 트래블러(Lv.5) ➔ 전설의 여행 챔피언(Lv.6)
  - 레벨업 시 화려한 콘페티(폭죽) 파티클과 전용 축하 팝업

### 3. 오늘의 퀘스트 & 실시간 연동
- 실제 체크리스트 상태와 100% 동기화되는 미션 시스템:
  - 워밍업! 준비물 5개 챙기기
  - 스마트 여행! 전자기기 준비 완료
  - 안전제일! 여행 서류 완벽 확인
  - 필수 준비물 마스터하기
  - 짐 싸기 열풍! 준비물 10개 체크
  - 퍼펙트 패커! 전체 준비물 100% 달성
- 미션 달성 시 실시간으로 **보상 상자 열기 🎁** 버튼 활성화 (중복 수령 방지)

### 4. 랜덤 보상 상자 & 수집 도감 (컬렉션)
- **보상 상자 개봉 시네마틱**:
  - 상자가 좌우로 흔들리며 반짝이는 파티클과 함께 개봉
- **3단계 등급 시스템**:
  - **일반 (Common)**: 여행 별 스티커, 작은 구름 스티커, 여행 가방 스티커, 네잎클로버, 종이비행기
  - **희귀 (Rare)**: 황금 비행기 배지, 반짝이는 여권 스티커, 모험가의 나침반, 레트로 즉석카메라, 여행자의 선글라스 (착용 가능)
  - **특별 (Special)**: 세계 여행자 배지, 마스터 골든 크라운 (착용 가능), 무지개 열기구 스티커, 탐험가의 사파리 모자 (착용 가능)
- **중복 보상 보호**: 이미 획득한 아이템이 다시 나오면 행운 경험치 +15 XP로 자동 환전
- **캐릭터 꾸미기**: 획득한 모자, 왕관, 선글라스를 가방 캐릭터 '캐리'에게 직접 착용/해제 가능

### 5. 여행 준비 대시보드 & 영구 저장
- 여행 제목, 목적지, 출발일 입력 및 **D-Day 실시간 자동 계산**
- 준비율 100% 달성 시 축하 팡파레 & 특별 완료 화면
- **브라우저 localStorage 연동**: 새로고침 후에도 모든 준비물 체크 상태, 레벨/경험치, 미션 달성 현황, 도감 수집 목록, 캐릭터 착용 상태 완벽 유지

## 🛠️ 기술 스택
- **프론트엔드**: React 18, Vite
- **스타일링**: Pure Vanilla CSS (CSS Custom Properties & Keyframes Animation)
- **아이콘**: Lucide React
- **시각 효과**: Canvas Confetti, SVG Interactive Character Graphics
- **상태 & 저장**: React Custom Hooks + localStorage 안전 저장소
